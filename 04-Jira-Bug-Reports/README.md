# Jira and Bug Reporting

## Bug Reporting Practice

Examples practiced:
- Transfer shows successful but recipient does not receive funds.
- Withdrawal shows successful but cash is not dispensed.
- Food delivery payment succeeds and customer is debited, but order remains unpaid.

For each defect, severity and priority were evaluated.

## Bug Lifecycle
Tester reports → QA Lead assigns → Developer fixes → Developer marks corrected → Tester verifies → Closed/Completed.
