# API Testing and Postman

API testing was practiced using sample REST API endpoints.

## Checks Practiced
- HTTP status codes
- GET requests
- Response body validation
- JSON structure
- Response data verification
- Basic API test scenarios

A successful API request commonly returned HTTP **200 OK**.

## QA Focus
The objective is not only to confirm that an API responds, but also to verify that the response contains the expected data and structure.
