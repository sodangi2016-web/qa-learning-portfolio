# Test Plan

## Food Delivery Application Test Plan

### Scope
- Registration and login
- Search
- Cart
- Order placement
- Payment
- Order tracking

### Testing Types
- Functional testing
- Positive testing
- Negative testing
- Boundary testing
- Regression testing

### Out of Scope
Physical address verification, phone/email verification, and national ID verification.

### Risks
Payment failures, incorrect order status, unavailable products, and tracking issues.
